# داده‌های رتبه و قبولی

فایل‌ها به تفکیک سال مرتب شده‌اند.

ستون‌های اصلی: سال، گروه آزمایشی، رتبه کشوری، رتبه در سهمیه، سهمیه، رشته قبولی و دانشگاه قبولی.

از داده‌های ۱۴۰۲ به بعد، ستون «نوع دوره قبولی» نیز ثبت می‌شود تا مواردی مثل روزانه، تعهدی، پردیس، شهریه‌پرداز، آزاد و آزاد خودگردان از هم جدا باشند.
